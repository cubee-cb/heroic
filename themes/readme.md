# Themes

My custom/edited css themes for Heroic.

- [EmmiTech](EmmiTech.css) (Heroic 3.0) - My main theme for Heroic 3.0. Based on my 2.0 theme, it makes various adjustments to the layout and colour scheme, and hides a bunch of elements I don't need. Game cards are smaller, have a hover zoom effect, and use frosted glass for the overlay buttons.
- [epicvampire-lavendar](epicvampire-lavendar.css) (Heroic 2.0) - A combination of Dracula's colour scheme with the Unreal theme. Also has various adjustments to unify the styling and hide some elements I don't care for.
